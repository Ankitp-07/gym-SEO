### Phase 0 Intentional Anti-SEO Checklist
These are things we deliberately **left out** — we will add them one by one:

- ❌ No `<meta name="description">` on either page
- ❌ No `lang` attribute or `viewport` meta on `<html>`
- ❌ No `<meta name="robots">` tag
- ❌ No canonical tag
- ❌ No Open Graph / Twitter Card tags
- ❌ No structured data / JSON-LD schema
- ❌ No `robots.txt`
- ❌ No `sitemap.xml`
- ❌ No `404.html`
- ❌ No `.htaccess` redirect rules
- ❌ Generic `<div>` layout — no semantic HTML5 tags (header, nav, main, section, footer)
- ❌ Images have no `alt` text
- ❌ Image file names are generic (`trainer-rahul.jpg`, not descriptive for SEO)
- ❌ Images not in WebP format
- ❌ No `loading="lazy"` on images
- ❌ No `fetchpriority="high"` on hero image
- ❌ No preload for critical assets
- ❌ CSS not minified
- ❌ JS not deferred
- ❌ No favicon or `theme-color`
- ❌ No accessibility features (skip link, ARIA labels)
- ❌ No `<title>` is optimised (50-60 chars with keyword + brand + location)
- ❌ No breadcrumb navigation
- ❌ No internal linking strategy
